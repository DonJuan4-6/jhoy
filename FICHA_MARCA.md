# Ficha de marca

- **Nombre de la aplicación:** JHOY
- **Marca visible:** SWAREH
- **Iniciales:** SWH
- **Eslogan:** Consigue tu Hardware, para tareas suaves o fuertes
- **Público objetivo:** Aficionados a las computadoras que quieren actualizar, armar o mejorar su equipo.
- **Propuesta de valor:** SWAREH reúne componentes y periféricos para distintos presupuestos, con información clara de precio y disponibilidad y una compra simulada sencilla para elegir el hardware adecuado con confianza.
- **Categorías:** Periféricos, GPU, CPU y Almacenamiento.
- **Identidad visual:** Azul para acciones y selección; gris y blanco para fondos, tarjetas y textos secundarios.
